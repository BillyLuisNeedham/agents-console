Reference · Agent graphs

Vocabulary

The small set of words needed to reason about graph-based agent systems without getting trapped in framework jargon.

Agentic system Any system that combines an LLM with tools, retrieval, memory, or orchestration to perform work. Anthropic uses this as the umbrella term for both workflows and agents.
Workflow An agentic system whose path is predefined in code. Routing, prompt chains, and fixed approval gates are workflows.
Agent An agentic system where the model dynamically directs the next action from environmental feedback. The loop decides; the code provides tools and boundaries.
Graph An explicit control-flow structure for an agentic system. Nodes perform work; edges choose what runs next; state records what the run knows.
State The current snapshot of the graph run: task, messages, decisions, intermediate results, and progress markers.
Node A function that receives state and returns a partial state update. It may call an LLM, use a tool, or run ordinary deterministic code.
Edge A transition from one node to another. Fixed edges always run; conditional edges choose destinations from state.
Entry point The first node(s) that run when a graph starts, declared with an edge from the virtual START node. Multiple entry points run in parallel; a conditional entry point routes from START based on input.
Recursion limit The maximum super-steps a single graph execution may take — 25 by default — before the runtime raises GraphRecursionError. The seatbelt that makes a loop without an exit fail loudly.
Channel One key in the state schema, with its own merge rule. Each channel receives updates independently, so two nodes writing different channels never conflict.
Reducer The merge rule for one state field, `(current, update) => newValue`. It decides whether a node update overwrites, appends, accumulates, or otherwise combines with existing state. Default is overwrite.
Super-step One execution round in the graph runtime. Nodes activated by the previous round may run in parallel, then their updates become input to the next round.
Checkpoint A persisted snapshot of graph state at a super-step boundary. It enables resumption, recovery, time travel, and human approval workflows.
Thread A scoped run or conversation identified by thread_id. Checkpoints are stored against a thread so it can be resumed later.
Interrupt A deliberate pause inside a node, usually to wait for human input. Resuming supplies the value that the paused function receives.
Store Long-term memory outside one graph thread. Use it for user preferences, facts, and shared knowledge that should cross conversations or runs.
Command A LangGraph primitive that can combine a state update with dynamic routing, or resume an interrupted run with a value.
Send A LangGraph primitive for dynamic fan-out: create one invocation of a node for each item in a list, each with its own input state.

Fast mental test

When reading an agent architecture, ask four questions:

  1. State: what does the system remember?
  2. Nodes: where does work happen?
  3. Edges: who chooses what happens next?
  4. Checkpoints: can execution pause, resume, or be audited?
