# Attempt logs are derived from the harness stream

Claude and cursor harnesses spawn with `--output-format stream-json --verbose`; the pump tees the raw stream to `<id>.stream.jsonl` and derives the human-readable `<id>.log` from it live — assistant text verbatim, one `[tool] Name: summary` line per call, unparseable lines passed through. This reverses what `NN.log` has meant since ADR-0002: it was raw harness bytes (empty until exit under `--output-format text`); it is now a derived view that can be tailed mid-run and reads in order after a crash. The same stream applies to every spawn site — implement, resolver, grader, head-to-head — and `spawned`/`exited` events grow the facts that would have diagnosed #41 and #42: argv with the prompt elided, cwd, branch, commit SHA, engine-set env on spawn; log tail and outcome-file existence on exit and in the crash interrupt body. Closes issue #43.

**Considered options**: keeping `NN.log` raw and converting at exit was rejected — a kill loses everything, which is the exact failure the issue reports. Deriving on the snapshot cadence or in the UI was rejected — the pump is the one place the bytes already flow through live.

**Consequences**: opencode has no stream-json, so its `NN.log` stays raw stdout — two log dialects in one `runs/` directory, accepted because opencode's raw output is already live and readable. The stream parser must pass through what it doesn't recognize: the stream-json schema drifts with harness releases, and a silently degrading log is worse than a raw one. Grader `trim.log` artifacts and `/api/log` now read derived text rather than raw bytes. Stream-file naming follows the events module's existing rotation contract (ADR-0003).

**Amendment (issue #161, ADR-0032)**: the Console no longer tails a derived log by fetching `/api/log` on the snapshot cadence. A selected (or hovered) card is subscribed over the Console's WebSocket. The server sends the followed log's last 64 KiB window, then pushes new bytes as the file grows, using `fs.watch` on `runs/` with a 2 s stat as backstop. Picking another attempt or the Stream file, and "load earlier", are requests that read the same byte ranges `/api/log` serves. The derived log, its Stream file and their naming are untouched.
