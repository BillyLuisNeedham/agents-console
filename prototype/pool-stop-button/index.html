Prototype · throwaway · issue #97

Stopping a finished pool's server from the Console

The question: when a pool reaches done, the Console shows a "Stop server" button. Press it and the pool's server shuts down. What does the page (and any other open tab) show once the server is gone, and can it tell "stopped on purpose" apart from "crashed" and "lost the network"?

This page simulates one pool server and up to two browser tabs looking at it. Nothing real runs. Press buttons on the right, or follow a walkthrough at the bottom. The state re-renders after every press; what just changed is highlighted. The four design choices from the issue are toggles, so you can feel each answer rather than argue it.
