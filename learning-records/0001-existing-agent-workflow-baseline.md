# Existing agent workflow and prior knowledge baseline

Billy is a senior TypeScript/Kotlin engineer with substantial experience using AI agents to build software. He already uses a deliberate multi-agent process that moves from grilling, to spec, to tickets, to implementation, with narrow context handed between agents.

## Evidence

Billy described this workflow directly in the initial teaching interview. He also reported mild prior familiarity with nodes, edges, and state machines, but said he has not used those concepts recently.

## Implications

Do not re-teach programming or basic AI-agent usage. Start by refreshing graph vocabulary, mapping it onto his existing handoff workflow, and focusing on architectural trade-offs. Use TypeScript examples and make the first hands-on milestone a small graph that exposes state, routing, persistence, and approval gates.
